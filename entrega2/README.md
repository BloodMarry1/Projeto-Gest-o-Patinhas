# Gestão Patinhas: Sistema de Acolhimento Animal

Aplicação desktop desenvolvida em Python 3 e GTK 3 para o gerenciamento de ONGs de proteção animal.

## Pré-requisitos
- Python 3.12+
- Biblioteca GTK 3
- `mysql-connector-python` e `certifi`

## Como Instalar e Executar

1. Clone o repositório ou abra a pasta do projeto.
2. Crie e ative um ambiente virtual:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
